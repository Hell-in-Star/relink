# Логотип ReLink — система v4.1 (листопад 2026)

Актуальний кит: `assets/source/лого/v4.1/` (svg / png / pdf CMYK / web) + опис у `README.md` там же.
Архіви для завантаження з брендбука: `assets/relink-logo-kit.zip` (все), `relink-logo-svg.zip`,
`relink-logo-png.zip`, `relink-logo-pdf.zip`, `relink-logo-mono.zip`, `relink-avatars.zip`, `relink-logo-web.zip`.

## Основне рішення

Єдине лого бренду — **горизонтальний лендмарк**: дуги-стрілки ліворуч + wordmark «ReLink».
«Re» і дуги — бурштиновий градієнт `#DEA102 → #ECC668`; «Link» — графіт `#394050` на світлому фоні або білий на темному.
Wordmark — намальовані контури, його не набирають шрифтом.

Старе лого (дуги зверху і знизу, wordmark Space Grotesk) і монограма «RL» **виведені з ужитку** — лежать в `archive/лого-v4.0-старе/`.

## Шість версій (кожна для світлого `on-light` і темного `on-dark` фону)

| Версія | Файл | Коли |
|---|---|---|
| Основне | `relink-horizontal-on-light/on-dark` | Усе щоденне: документи, сайт, email-підпис, футер, темні слайди |
| З підписом «your recruitment partner» | `relink-horizontal-tagline-on-light/on-dark` | **Тільки промо** (банер, обкладинка LinkedIn, титул презентації) і **тільки коли лого ширше 60 мм / 300 px** |
| Знак з написом | `relink-badge-on-light/on-dark` | Квадратні місця: стікер, печатка, вотермарк |
| Іконка | `relink-icon` | Фавікон, розміри до 32 px |
| Аватар | `relink-avatar-graphite` (основний), `relink-avatar-amber` (запасний) | LinkedIn, Facebook, Instagram, Threads |
| Монохром | `relink-horizontal-mono-graphite/white` | Тиснення, тамподрук, шовкодрук |

Правило підпису закриває питання «то з підписом, то без»: вибір робить формат носія, а не смак.

## Мінімальні розміри і охоронне поле

- Основне лого: від 120 px на екрані, від 25 мм у друці.
- Лого з підписом: від 300 px / 60 мм. Виняток — ручки: від 40 мм (окремий макет, `assets/source/друк/2026-11-ручки-лого/`).
- Нижче 32 px — тільки іконка.
- Охоронна зона — висота літери «R» з усіх боків.

## Старі вихідники контурів
