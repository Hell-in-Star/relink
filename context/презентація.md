# Презентація компанії ReLink

Джерело правди — `presentation/relink-presentation.html` (9 слайдів, 1280×720px,
16:9). PDF і PPTX — похідні, генеруються з нього (див. «Перезбірка» нижче).

## Структура (9 слайдів)

1. **Обкладинка** — коло-схема з виносками (Виробничі / Інженерно-технічні /
   Офісні / Управлінські), лого-мітка в центрі кола, заголовок «Знаходимо
   рішення, що працюють», сегменти Defense/Production/Sales/Back office.
2. **Чому найм — це критично?** — темна плашка з поясненням, ланцюжок
   наслідків (Незакрита вакансія → Простій виробництва → Втрачені контракти).
3. **З ким працюємо** — B2B-клієнти, B2C-кандидати, ветерани (3 колонки, темний фон).
4. **Наші послуги** — класичний рекрутинг, складний інженерно-технічний
   підбір, спеціальні формати (3 колонки, світлий фон).
5. **Спеціальні формати співпраці** — масовий підбір, навчальний центр,
   зовнішній HR-партнер, терміновий підбір (горизонтальні смуги).
6. **Класичний рекрутинг** — 8 карток етапів процесу (від заявки до
   гарантійного супроводу) + плашка-акцент, темний фон.
7. **Додаткові сервіси** — безкоштовні / платні, розріз світлий/темний.
8. **Наші переваги** — статистика (90% / 10 000+ / 87%) + 4 вузли переваг
   на пунктирній дузі.
9. **Контакти** — «Готові почати?», картки контактів (плейсхолдери в дужках).

## Головні дизайн-рішення

- **Радіальні градієнти замість діагональних.** На відміну від фірмових
  діагональних градієнтів з `/context/палітра.md` (використовуються в
  брендбуку, лого), фони слайдів презентації — радіальні градієнти
  (`radial-gradient(ellipse ... at <кут>)`), по 2 накладені еліпси на
  кожному фоні (бурштиновий + графітовий/блакитний акцент по кутах). Це
  свідоме рішення саме для презентації, не суперечить бренду, але це
  винятку варто пам'ятати при розробці нових матеріалів «під презентацію».
- **Коло-схема з виносками на обкладинці.** Технічна/креслярська естетика:
  тонкі лінії кола, маркери-точки, лінії-виноски до підписів. Виноски мають
  **правило розриву**: лінія від маркера йде під кутом, потім коротким
  горизонтальним відрізком — і закінчується з невеликим зазором ДО тексту
  підпису (не впритул). Той самий прийом можна повторно використовувати в
  інших схемах презентаційного стилю.
- **Пігулки з бурштиновою рамкою.** Наскрізний елемент — овальні пігулки
  (border-radius 999px), тонка бурштинова рамка, бурштиновий текст, прозора
  заливка. Використано для сегментів на обкладинці, ланцюжка наслідків
  (слайд 2), деяких заголовків-міток секцій.
- **Лого-мітка в колі (слайд 1)** — трасована з `avatar-dark-square.svg`
  (дуги-стрілки + напис), кольори навмисно ІНВЕРТОВАНІ відносно вихідного
  файлу (деталі — `/context/логотип.md`).

## Цифри, підтверджені замовником

- **90%** вакансій закриваються у погоджений термін (слайд 8).
- **10 000+** власна база кандидатів (слайди 1, 8).
- **87%** кандидатів проходять гарантійний термін (слайд 8).
- **21 день** — терміновий підбір, від заявки до оферу (слайд 5).

Контакти на слайді 9 — ще плейсхолдери в дужках, НЕ підтверджені
(`docs/план.md`, відкрите питання). Формулювання ланцюжка наслідків на
слайді 2 («Незакрита вакансія → Простій виробництва → Втрачені контракти»)
— наше, не перевірене замовником (там само).

## Перезбірка PDF і PPTX

Джерело — тільки `relink-presentation.html`; PDF/PPTX вручну НЕ редагувати,
перезбирати після кожної затвердженої правки HTML:

```
cd presentation
npm install                       # один раз
node build-pdf.js                 # -> relink-presentation.pdf
node pptx-assets/render-assets.js # перегенерувати активи PPTX
python build-pptx.py              # -> relink-presentation.pptx
```

Якщо PDF раптом зібрався «з полями» (вміст сторінки менший за саму сторінку) —
див. блок про це в `CLAUDE.md`, причина в масштабуванні Windows, що впливає
на друкований рендер Chromium/Skia; фікс уже в `build-pdf.js` (`scale: 1.5`).

Детальний звіт з архітектурою PPTX (що картинка, що редагована фігура) і
відомими обмеженнями — `presentation/pptx-звіт.md`.
