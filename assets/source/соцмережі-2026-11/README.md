# Соцмережі ReLink — обкладинки і мокапи профілів (листопад 2026)

Слоган: «Знаходимо людей, що створюють результат» (погоджений на банері для виставки).

## Обкладинки (`обкладинки/`, PNG у подвійній роздільності)
| Файл | Розмір для завантаження | Де |
|---|---|---|
| `relink-cover-linkedin-company-dark/light.png` | 1128×191 (файл 2256×382) | сторінка компанії LinkedIn |
| `relink-cover-linkedin-personal-dark/light.png` | 1584×396 (файл 3168×792) | особисті профілі співробітників |
| `relink-cover-facebook-dark/light.png` | 851×315 (файл 1702×630) | бізнес-сторінка Facebook |

Основна — темна (dark). Світла — запасна, якщо замовник захоче світлий профіль.
Лівий нижній кут вільний: його перекриває аватар. Текст FB-обкладинки в центрі,
бо на телефоні Facebook обрізає боки.

Аватар — `assets/relink-avatars.zip` (avatar-graphite).

## Мокапи (`мокапи/`)
Схематичні профілі для брендбука: як виглядатиме аватар + обкладинка разом.
Пости в мокапі Instagram і текст у Threads — приклади стилю, не реальні публікації.

## Вихідник
`вихідник/build.py` (обкладинки) і `mock.py` (мокапи) — HTML → Playwright-скріншот.
Шляхи всередині вказують на робочу машину Claude, перед запуском замінити на
`assets/source/шрифти/` і `assets/source/лого/v4.1/`.
