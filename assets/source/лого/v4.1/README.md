# Логотип ReLink — система v4.1 (листопад 2026)

| Файл | Що це | Де використовувати |
|---|---|---|
| relink-horizontal-on-light / on-dark | Основне лого | Документи, сайт, email-підпис, усе щоденне |
| relink-horizontal-tagline-on-light / on-dark | Лого з підписом «your recruitment partner» | Тільки промо (банери, обкладинки, обкладинка LinkedIn, титул презентації) і тільки коли лого ширше 60 мм / 300 px |
| relink-badge-on-light / on-dark | Знак з написом у колі | Квадратні місця: стікер, печатка, вотермарк |
| relink-icon | Тільки дуги | Фавікон, розміри до 32 px |
| relink-avatar-graphite | Аватар (основний) | LinkedIn, Facebook, Instagram, Threads |
| relink-avatar-amber | Аватар (запасний) | Коли графіт зливається з оточенням |
| relink-horizontal-mono-graphite / white | Монохром | Тиснення, тамподрук, шовкодрук |

on-light = для світлого фону, on-dark = для темного фону.
Кольори: бурштиновий градієнт #DEA102 → #ECC668; «Link» — графіт #394050 (світлий фон) або білий (темний фон).
Формати: svg/ (вектор, основне джерело), png/ (прозорий фон, 3000 px по ширині для горизонтальних), pdf/ (CMYK для друку), web/ (фавікони 512/180/32 + SVG для сайту).
Wordmark «ReLink» — це намальовані контури, не набирати його шрифтом.
