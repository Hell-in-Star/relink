Оновлені версії візиток, які друкували раніше. Зміст і розкладка ті самі,
змінено тільки те, що розходилось із брендом v4.1:
- лого v4.1 (бурштиновий градієнт; на темному фоні «Link» білий);
- шрифти Geologica (ім'я, посада, підпис під QR) + Onest (решта) замість застарілих Inter / Oswald;
- темний фон — графітовий градієнт #394050 → #4A5266.

## Вихідник (`вихідник/`)
HTML у міліметрах; шрифти і лого підтягуються з репо відносними шляхами
(`assets/source/шрифти/`, `assets/source/лого/v4.1/svg/`).
Нову візитку робити копією HTML зі зміною імені/посади/контактів, далі:
Playwright → PDF 94×54 мм → Ghostscript у CMYK з кривими:
```
gs -o out.pdf -sDEVICE=pdfwrite -dNoOutputFonts -sColorConversionStrategy=CMYK -sProcessColorModel=DeviceCMYK -dPDFSETTINGS=/prepress in.pdf
```
Увага: Chrome дає сторінку на ~0.3 мм більшу за 94×54; після gs обрізати
MediaBox до 266.457×153.071 pt (так зроблено у фінальних файлах).
