# SMM ReLink — карта теки

Ця тека містить дослідження і стратегію присутності ReLink у соцмережах.
Структура однакова для кожної мережі: спочатку дослідження (ринок, алгоритм,
правила гри), потім стратегія (що конкретно робимо).

## Правило: де що описувати

- **Загальний файл** (`стратегія-загальна.md`, `дослідження-зведене.md`) —
  описує тільки те, що спільне для всіх мереж: позиціонування, tone of voice,
  спільна інфраструктура, порівняння мереж між собою.
- **Мережевий файл** (`linkedin/…`, `facebook/…` тощо) — описує тільки
  відмінності й специфіку конкретної мережі: її алгоритм, формати, ритм
  постингу, окремі правила.
- Вміст **не дублюється** між загальним і мережевими файлами. Якщо якийсь
  факт стосується лише однієї мережі — він живе тільки в її файлі.

## Структура теки

```
smm/
  README.md                      — цей файл
  стратегія-загальна.md          — спільна стратегія по всіх мережах (каркас)
  дослідження-зведене.md         — зведене порівняння мереж (каркас)
  linkedin/
    дослідження.md               — дослідження ринку/алгоритму LinkedIn
    стратегія.md                 — опис і посилання на затверджену стратегію
  facebook/
    дослідження.md               — каркас, не розпочато
    стратегія.md                 — каркас, не розпочато
  instagram/
    дослідження.md               — каркас, не розпочато
    стратегія.md                 — каркас, не розпочато
  threads/
    дослідження.md               — каркас, не розпочато
    стратегія.md                 — каркас, не розпочато
```

## Джерела правди

- **LinkedIn:** стратегія — `relink-linkedin-strategy.html` у корені репо
  (опублікований через GitHub Pages, деталі в `smm/linkedin/стратегія.md`).
  Дослідження — `smm/linkedin/дослідження.md`.
- **Facebook / Instagram / Threads:** ще не існує — наповнюватимемо окремими
  сесіями.
