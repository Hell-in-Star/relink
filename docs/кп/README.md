## Що уточнити в Олени (заповнюється один раз)
1. Гарантія: скільки місяців; безкоштовна заміна чи повернення коштів.
2. Оплата: передоплата / частинами / після виходу кандидата.
3. Вартість: у КП принцип чи конкретні суми.
4. Масовий підбір: як рахуємо.
5. Платні сервіси (психотестування, конкурс/асесмент): ціна чи «за запитом».
6. Через скільки днів клієнт бачить перших кандидатів.
7. Скільки днів дійсна пропозиція.
8. Чий контакт на останній сторінці (Олена чи Ольга Дабіжа).
9. Слоган обкладинки: «Знаходимо рішення, що працюють» чи «Знаходимо людей, що створюють результат».
10. Кейс, який можна назвати клієнту.
